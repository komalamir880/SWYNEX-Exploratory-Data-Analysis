# SWYNEX — Task 2: Exploratory Data Analysis

This repository contains the EDA deliverables for SWYNEX Technologies internship Task 2.

## Files
- `SWYNEX-Exploratory-Data-Analysis.xlsx` — workbook with summary statistics, seven key insights, cleaned source data, country/month/city summaries, outlier check, and charts.
- `SWYNEX-EDA-Task2-Report.md` — written explanation of the method, findings, and limitations.

## Analysis performed
- Descriptive statistics for Amount
- Aggregation by country, city, and month
- Monthly trend comparison
- Outlier screening using the 1.5×IQR rule
- Bar chart of total amount by country and line chart of monthly total amount

## Important note
The supplied dataset uses `example.com` email addresses and contains no currency field. Findings are descriptive of the provided sample only; no real-world customer identities or currency are assumed.
